# PolkaInsight

Учебная интеллектуальная аналитическая система комплексного анализа Polkadot (DOT).

**Команда:** «Поцелуй Комара»  
**Практическая работа:** № 3–2

## Что реализовано

- технический анализ: RSI, MACD, SMA, EMA, Bollinger Bands;
- фундаментальная оценка по пяти критериям и официальной документации Polkadot;
- ончейн-анализ через открытый Polkadot Public RPC без ключа;
- анализ новостей и индекса Fear & Greed;
- интегральная оценка от 0 до 100 с перенормировкой весов при пропусках;
- выявление противоречий, рисков и автоматическое заключение;
- сравнение DOT и BTC, интерактивные графики;
- история исследований в SQLite и выгрузка отчёта в Markdown/HTML;
- онлайн-режим и полностью автономный демонстрационный режим.

Демонстрационный режим использует **синтетические данные**. Они не являются актуальными котировками.

## Запуск на Windows

Самый простой способ — запустить `start.bat`: скрипт создаст окружение при необходимости и откроет сервер приложения.

Или выполните в командной строке из папки проекта:

```bat
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m streamlit run app.py
```

Откройте `http://localhost:8501`. При первом запуске автоматически показывается демонстрационный анализ. Выберите период и нажмите **«Запустить анализ»**.

## Онлайн-источники

CoinGecko, Binance, Alternative.me, Google News RSS, Cointelegraph RSS и Polkadot Public RPC используются **без регистрации и API-ключей**. Настраивать переменные окружения для учебной демонстрации не нужно.

Последовательно используются Google News RSS и тематическая лента Cointelegraph Polkadot. Если оба сайта недоступны, интерфейс показывает локальные учебные примеры, но не использует их в онлайн-оценке. Публикации старше 30 дней отображаются как архив и также исключаются из расчёта актуальных настроений.

Ончейн-модуль получает среднее количество extrinsics в двух выборках блоков напрямую через открытые узлы Polkadot RPC. Если все узлы недоступны, раздел заполняется локальными учебными значениями с явным предупреждением: они не выдаются за реальную статистику блокчейна.

## Запуск без графического интерфейса

```bat
.venv\Scripts\python.exe -m polkainsight --mode demo --days 90 --output analysis.md
.venv\Scripts\python.exe -m polkainsight --mode online --days 90 --output analysis.md
```

## Методика

Каждый модуль выдаёт оценку от 0 до 100. Итог рассчитывается по формуле:

```text
IA = 0,30 × TA + 0,25 × FA + 0,25 × OA + 0,20 × SA
```

При отсутствии модуля его вес исключается, а оставшиеся веса нормализуются. Расхождение оценок на 30 и более баллов фиксируется как противоречие. Техническая оценка использует веса RSI 20%, MACD 25%, SMA 20%, EMA 20%, Bollinger Bands 15%.

Фундаментальные баллы являются учебной экспертной оценкой по заранее заданной методике, а не данными биржи. Новостной классификатор использует небольшой словарь и не заменяет полноценную языковую модель.

## Готовые материалы для сдачи

Папка `deliverables/` содержит отчёт, презентацию на 15 слайдов, исходное ТЗ, протокол из 17 проверок, руководство пользователя, архитектурные схемы, снимок интерфейса, демонстрационные и реальные онлайн-данные. Файлы CSV в `deliverables/data/` содержат исходный временной ряд и обработанные значения индикаторов.

## Структура

```text
app.py                     интерфейс Streamlit
polkainsight/sources.py    внешние API и обработка ошибок
polkainsight/demo.py       автономные синтетические данные
polkainsight/indicators.py технические индикаторы
polkainsight/analysis.py   четыре модуля и комплексная оценка
polkainsight/pipeline.py   единый сценарий исследования
polkainsight/storage.py    SQLite и история
polkainsight/report.py     автоматический отчёт
scripts/                   генерация учебных материалов
```

Результат анализа носит информационно-аналитический характер и **не является индивидуальной инвестиционной рекомендацией**.
